Corrección de "null" en Nombres

❌
Problema

Los nombres de usuarios aparecían con la palabra "null" al final cuando el campo apellido_materno estaba vacío.

Ejemplo: "Alberto Cano null", "Alejandro Licona null"

✓
Solución

Implementación de función getFullName con filtrado de valores nulos/undefined usando .filter(Boolean).join(' ')

Antes (Incorrecto) 
const fullName = `${nombre} ${apellido_paterno} ${apellido_materno}`;
Después (Correcto) 
const getFullName = (user: User) => {
  return [user.nombre, user.apellido_paterno, user.apellido_materno]
    .filter(Boolean)
    .join(' ');
};

Fix Principal: Error al Crear Grupos

❌
Problema

Error "Error al crear el grupo - No se pudo crear el grupo" al intentar crear grupos de chat.

🔍
Causa Raíz

La política RLS de Supabase requiere que auth.uid() esté dentro del array participants.

Política RLS de Supabase 
CREATE POLICY "chat_rooms_insert_participant"
  ON chat_rooms
  FOR INSERT
  TO authenticated
  WITH CHECK (auth.uid() = ANY(participants));

Problemas Específicos Corregidos

# Problema Solución
1 User ID no siempre al inicio del array [user.id, ...participantIds.filter(id => id !== user.id)]
2 Verificación de sesión insuficiente await supabase.auth.getSession() antes del INSERT
3 Errores genéricos sin contexto Manejo específico por código de error
4 Duplicados en participants [...new Set(participantIds)]
5 Mismatch entre auth UID y user.id Verificación explícita antes de INSERT
